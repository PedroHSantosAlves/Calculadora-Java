Calculadora em Java

Calculadora de linha de comando feita em Java puro, sem bibliotecas externas. O projeto foi criado para praticar lógica de programação, tratamento de erros e organização de código.

Funcionalidades
Soma, subtração, multiplicação, divisão e potência
Aceita números decimais (com ponto ou vírgula)
Tratamento de entradas inválidas (letras, campo vazio etc.)
Bloqueio de divisão por zero com mensagem de erro
Histórico das operações feitas durante a execução
Menu interativo que se repete até o usuário escolher sair
Tecnologias
Java 14 ou superior (usa a sintaxe de switch com ->)
Nenhuma dependência externa


Exemplo de uso

======================================
=== CALCULADORA EM JAVA ===

Escolha uma opção:
1 - Soma
2 - Subtração
3 - Multiplicação
4 - Divisão
5 - Potência
6 - Ver histórico
0 - Sair
Opção: 4
Primeiro número: 10
Segundo número: 4
Resultado: 10 / 4 = 2.5

Tentando dividir por zero:
Opção: 4
Primeiro número: 8
Segundo número: 0
Erro: não é possível dividir por zero.
